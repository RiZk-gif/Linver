# Linver

**Linux Version Information**

Linver is a lightweight Linux system information viewer built with Python and GTK4.

Linver is inspired by Windows Winver, bringing a similar version information experience to Linux.

ini Linver gw hanya dari referensi dari Winver

## Features

- Linux distribution detection
- OS version information
- Linux kernel detection
- CPU architecture detection
- Desktop environment detection
- Window manager detection
- Display server detection
- Native GTK4 interface with Adwaita styling

## Requirements

- Python 3
- GTK4
- PyGObject

## Installation

### 1. Install dependencies

Open a terminal and run:

```bash
sudo dnf install python3 python3-gobject gtk4 git
```

### 2. Clone the repository

```bash
git clone https://github.com/RiZk-gif/Linver.git
```

### 3. Enter the project directory

```bash
cd Linver
```

### 4. Run Linver

```bash
chmod +x Linver
./Linver
```

## Updating

To update Linver to the latest version:

```bash
cd Linver
git pull
```

Then run Linver again:

```bash
./Linver
```
